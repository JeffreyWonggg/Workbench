# 工作台 Workbench

完全离线运行的个人工作台。待办、周报、笔记、记账、菜谱、记谱（和弦谱）、资料库、项目、收藏、代码（git）、更新软件版本、局域网传文件都在同一套界面里，**数据保存在你自己的文件夹中，不上传任何服务器**。

---

## 一分钟上手

1. 双击 **`打开工作台.bat`** —— 启动本地服务并打开 `http://127.0.0.1:47321/`
2. 首次使用会要求**选择一个数据文件夹**（待办/周报/笔记等会写进去，建议专门建一个空文件夹，比如 `D:\WorkbenchData`）
3. 需要局域网传文件时，先双击一次 **`启用局域网访问.bat`**（见下文「局域网」）

> 建议始终用 `打开工作台.bat` 进入，即 `http://127.0.0.1` 这个地址。用 `file://` 直接双击 HTML 打开会缺少本地服务能力。

## 功能一览

| 页面 | 做什么 |
|---|---|
| **工作台**（首页） | 今天到期的待办、本周概览、可配置的工具启动菜单、DeepSeek 充值余额与当天/当月消费 |
| **项目** | 按项目聚合待办/笔记/周报工时/资料/代码/软件号；总览页显示每个项目的概况 |
| **待办** | 待办与状态、截止日、项目归属；逾期会在侧栏角标提醒 |
| **周报** | 按周记录各项目的工时与工作项；可从「已完成待办」一键填入；支持 AI 润色/扩写并导出 Markdown |
| **笔记** | 分级标题的块式笔记，支持表格、块内编辑、上下移动、项目归属 |
| **资料库** | 账号密码、路径、主机等条目；**主密码加密存储**（PBKDF2-SHA256 + AES-GCM），可记住密码、导出明文、从备份回滚 |
| **记账** | 记支出/收入（金额只填正数，收支由类型区分）、日期、分类（可自定义）与备注；本月支出/收入/结余统计（含日均、比上月）、关键词搜索、按类型筛选、上下月翻看；明文 `ledger.json`，已纳入云同步 |
| **菜谱** | 记录菜名、分类、食材清单、做法步骤；支持关键词搜索与分类筛选、展开收起全文；删除进回收站可恢复；`Ctrl+K` 可搜 |
| **记谱** | 吉他弹唱和弦谱：谱面就是一段纯文本（和弦一行、歌词一行），支持 `{C}歌词` 内联写法、粘贴清洗、对齐格式化、推荐调、擅长和弦、转调、点和弦试听（详见「记谱」一章） |
| **快捷方式** | 常用文件 / 文件夹 / 网址做成卡片，点一下用系统默认程序打开；可增删改，清单存在 `meta.json` 的 `shortcuts` 字段里 |
| **剪贴板** | 查看本地服务记录的剪贴板历史（`Alt+Q` / `Alt+E` 那套）：搜索、展开长文本、一键复制回剪贴板；只在本机 `127.0.0.1` 显示 |
| **收藏** | 把文件或整个文件夹拖进来就存进数据文件夹（本体进 `files/`，截图进 `screenshot/`）；卡片带缩略图预览、搜索、按「文件/截图」筛选、可另存回本机 |
| **代码** | 本机 git 仓库管理：扫描发现、状态、改动暂存/提交、历史与差异、分支、标签、获取/拉取/推送（含强制推送）、反向提交与硬回滚、发布流水、软件号（明文） |
| **局域网传文件** | 手机/其它电脑在同一 WiFi 下打开局域网地址即可上传下载（支持整个文件夹、打包下载） |
| **产品目录查询** | 读取 sqlite 索引库查询产品信息；另有一份只存在本机的自建目录 |
| **更新软件版本** | 编辑 `UpdateVersion.ini`：改版本、复制条目、发布前预览、一键发布；与「代码」页的标签/发布流水联动 |
| **回收站** | 软删除的待办/笔记/菜谱在这里恢复或彻底删除（资料库的条目加密存放，只能在资料库页里恢复） |
| **关于** | 本页所有文字（名称、简介、作者、版本、版权）都读根目录的 **`about.json`**，改完刷新即可 |

**通用**：深色/浅色主题、侧栏可拖动排序、侧栏底部「设置」可关掉不用的页面、`Ctrl+K` 命令面板（可搜页面/待办/笔记/资料/软件号/菜谱）、全局撤销（删除后 Toast 带「撤销」）、危险操作一律用页面内的确认弹窗（不用浏览器原生弹窗）。

**云同步（可选）**：待办/周报/笔记/记账/菜谱/软件号/资料库/余额加密后同步到腾讯云 CloudBase，手机浏览器打开 HTTPS 页面就能接着用；两台设备改同一处会保留冲突副本。请求也做得很省——不做后台轮询，切页/刷新不会白读云端（详见「云同步」一章）。

## 记谱（和弦谱）

和弦谱页的设计原则是**纯文本即唯一真源**：一首歌的谱面就是一整段文本，和弦占一行、歌词占一行，靠列对齐对上位置。转调、复制、打印、手工修改都只动字符，不依赖任何结构化格式——从网上复制来的谱子不用转换就能用。

### 输入方式（按推荐顺序）

1. **粘贴清洗**（覆盖绝大多数场景）：从网页/App 把谱子整段复制进来 → 点「粘贴清洗」，会去掉站点标记、装饰行和「原调 / 变调夹 / 歌手」这类头部信息，并把「上一行纯和弦 + 下一行带 `( )` 标记的歌词」合成内联写法 → 再点「对齐格式化」，把它摊回「和弦一行、歌词一行」并对齐 → 右侧预览确认。
2. **内联写法**：手打时写 `{Am}故事的小黄花`，不用自己数空格——和弦会落在 `{` 所在的那一列上方。注意 `[主歌]` 这种方括号是**段落标题**，别拿来包和弦。
3. **和弦面板 + 前缀补全**：面板里列的是当前调内的常用和弦（含你自己标进「擅长和弦」的），点一下插到光标处；在谱面里敲 `Am` 的前几个字符会弹候选，按 `Tab` 采纳。

### 其它

- **推荐调**：按谱面里出现的和弦算出黑键最少的调，一键切过去并刷新和弦面板
- **转调**：列表卡片上的「转调」选目标调（弹窗里同时列出推荐调），「应用」覆盖原曲、「应用并另存」留一份新歌
- **试听**：点预览或查看页里的和弦会发声（WebAudio 合成，无外部依赖、不走网络），音量在编辑器工具栏右侧
- **删除**：不做回收站，删掉后在 Toast 里可以「撤销」一次，歌会回到原来的位置

数据文件：`charts.json`（歌曲）+ `chart-settings.json`（擅长和弦、推荐调权重、音量）。**歌曲、擅长和弦、推荐调权重都纳入云同步**，手机上能接着电脑上的谱子继续用；只有音量留在各台设备——手机和电脑该各留各的（详见「云同步 → 同步哪些数据」）。

## 界面与设置

侧栏底部（数据文件夹和「项目」入口的下方）依次是**深色模式**和**设置**两个按钮，再下面是「Ctrl+K 搜索」提示。

### 设置：关掉不用的页面

「设置」里列出全部页面，勾选框控制它**是否出现在侧栏和 `Ctrl+K` 搜索里**。关掉一个页面意味着：

- 侧栏和 `Ctrl+K` 里都不再出现（两处始终一致）
- 其它页面上指向它的链接（比如项目页的「待办 / 笔记 / 代码」）**不会跳过去**，而是弹出提示说明该页面已被关掉，并给一个「打开设置」的入口，点了直接打开设置面板并把对应那一行高亮出来
- **页面本身没动**：直接输网址照样能打开，功能完全照旧，随时能勾回来
- **位置保留**：拖动排序存的是完整顺序（含关掉的页面），所以关掉再打开会回到原来的槽位，不会跑到末尾
- 全部关掉时侧栏会提示一句「侧栏是空的。点下面「设置」把页面打开。」；设置入口不受自身开关影响，不会把自己锁在外面

> 说明：关掉侧栏项**不省资源**。每个页面只有在你打开时才加载自己的 JS 和数据，侧栏那几行字不加载任何东西。真要省资源，该关的是「进入某页时的自动行为」（例如代码页一进去就递归扫描仓库）。

### 危险操作统一确认

删除、重置、导出、迁出这类操作用的是页面内的毛玻璃弹窗，**全库没有浏览器原生 `confirm()` / `alert()` / `prompt()`**（原生弹窗由系统绘制，和整套界面不是一个观感）。目前统一走 `Nav.ask()` 的有 14 处：回收站（彻底删除待办/笔记/菜谱、清空回收站）、资料库（重置、导出明文、彻底删除条目、批量迁出软件号）、快捷方式（删除卡片）、收藏（删除文件）、记账（删除记录）、更新软件版本（有未保存修改时发布）、产品目录查询（删除自建记录）、局域网传文件（删除文件/文件夹）；云同步面板的确认与冲突查看也复用同一套。周报、菜谱、记谱用的是各页自己的同款对话框（`<dialog>` + 同一套样式）。

行为与原生一致：**确定 → 执行；取消 / Esc / 点弹窗外的遮罩 → 放弃**。危险操作用红色按钮，并且**默认焦点落在「取消」**上，避免一路回车把东西删了；删除类操作大多还能在 Toast 里点「撤销」恢复。

### 本机偏好存在哪里

| 偏好 | `localStorage` 键 |
|---|---|
| 主题（深色/浅色） | `wb-theme` |
| 侧栏顺序 | `wb-nav-order` |
| 关掉的页面 | `wb-hidden-pages` |

这些**跟着浏览器走，不跟着数据文件夹走**：换电脑、换浏览器或清了站点数据，需要重新设一次（数据本身当然还在你的数据文件夹里）。

## 技术框架

**设计取向：零依赖、零构建、离线优先。** 没有 npm、没有 bundler、没有 CDN 请求，克隆下来就能跑。

| 层 | 用的东西 |
|---|---|
| 前端 | 原生 HTML + CSS + ES2020 JavaScript（无框架），模块以 IIFE 挂到 `window`（`Workbench` / `Nav` / `GitApi` / `Storage` / `VaultCrypto` 等） |
| 样式 | 单文件 `css/app.css`，CSS 变量 + `[data-theme]` 双主题；字体本地自托管（`fonts/*.woff2`） |
| 数据读写 | **File System Access API**：用户自己选数据文件夹，句柄存 IndexedDB，数据以纯 JSON 文件落地（`meta.json`、`todos.json`、`notes.json`、`reports.json`、`notes/`、`software.json`…） |
| 加密 | WebCrypto：PBKDF2-SHA256 派生密钥 + AES-GCM 加密资料库（`vault.json`），每次写入自动留 `vault.backup.json` |
| 本地服务 | **C# / .NET Framework**（`scripts/workbench-host.cs`，用 `csc` 编译成单个 `workbench-host.exe`），`HttpListener` 提供 HTTP 接口，WinForms 弹原生文件/文件夹选择框 |
| 数据库 | `sql.js`（SQLite 编译成 WebAssembly）在浏览器里只读查询 `.db` |
| 二维码 | 自带 `js/vendor/qrcode.js` |
| AI | 兼容 OpenAI 协议的 `chat/completions` 接口（DeepSeek / 火山方舟），密钥放本机 `js/openrouter.local.js`；首页余额卡片另查官方 `GET /user/balance` |

### 本地服务接口

| 接口 | 用途 |
|---|---|
| `GET /` 及静态文件 | 提供页面；有屏蔽名单，禁止路径穿越 |
| `POST /open` | 用系统默认程序打开本机文件/文件夹 |
| `POST /run-tool` | 按 `meta.json` 的 `tools` 配置启动本机程序 |
| `POST /publish`、`GET/POST /update-version-ini` | 更新软件版本的预览与发布 |
| `GET/POST /config` | 读写本机配置（如 `UpdateVersion.ini` 路径） |
| `POST /pick-file` | 弹 Windows 原生对话框（`mode=file` 选文件 / `mode=dir` 选文件夹） |
| `GET /fs/list` | 列目录（页面内目录浏览器用） |
| `/lan/*` | 局域网传文件的列表、上传、下载、删除、打包 zip |
| `/git/*` | `scan` / `status` / `log` / `diff` / `branches` / `tags` / `exec` |

**安全约束**（重要）：所有写操作都校验来源（只认 `http://127.0.0.1:47321`），局域网来源一律 403；`/git/*` 更进一步——**客户端只说“做什么动作”，命令行由服务端白名单拼装**，从根上避免参数注入；仓库必须位于已登记的代码根目录下，路径不允许含 `..`。

## 局域网传文件

1. 双击一次 **`启用局域网访问.bat`**。它会检查两件事并以普通用户身份完成能做的部分：
   - `http://+:47321/` 的 **URL 保留**（缺了服务就只能监听 127.0.0.1，局域网连不上）
   - **防火墙**是否放行 TCP 47321（仅当防火墙处于开启状态才需要）
   - 缺配置时会打印出需要**管理员权限执行一次**的命令（可直接交给 IT），并照常把服务重启好 —— 本机使用不受影响
2. 打开「局域网传文件」页，复制显示的地址（或让对方扫二维码），对方用浏览器打开即可上传/下载
3. 支持直接拖入整个文件夹；隐藏文件/文件夹（`.git` 等）会被跳过，这是设计如此
4. 同名文件**不会覆盖**已有的：上传时自动另存为 `报告 (1).pdf`，列表里两份都在（避免手滑把别人刚传的文件顶掉）

> 公司电脑若没有管理员权限：URL 保留和防火墙规则都无法自行添加，需要 IT 授权一次。局域网地址走的是明文 HTTP，因此**数据页（待办/资料库等）在其它设备上不可用**，页面会明确提示，只有不需要数据文件夹的「局域网传文件」等页面可用。

## AI 配置（可选）

周报的「AI 润色」需要一个模型密钥。在 `js/openrouter.local.js` 里写（该文件已 gitignore，不会进版本库）：

```js
window.DEEPSEEK_API_KEY = "sk-...";
window.ARK_API_KEY = "你的火山方舟 Key";
```

模型清单在 `js/weekly.js` 顶部的 `MODELS` 数组里，新增模型照着加一行即可。润色力度对应不同温度：保守润色 0.3 / 适度扩写 0.5 / 充分扩写 0.7。

## DeepSeek 余额（可选）

首页有一块「DeepSeek」，显示**充值余额**、**当天消费**、**当月消费**，用的是周报 AI 同一个密钥。三个数字的来源不一样：

| 数字 | 怎么来的 |
|---|---|
| **充值余额** | 官方接口 `GET https://api.deepseek.com/user/balance` 的 `topped_up_balance`（同一行还取 `total_balance` 当总额、`granted_balance` 当赠金），带 `Authorization: Bearer <你的 Key>`。实测该接口会回显 `access-control-allow-origin`，所以**浏览器直连就行，不经过本地服务，也不用重编译 exe** |
| **当天消费** | 余额快照差值：`当天最早一次记录到的余额 − 当前余额` |
| **当月消费** | 同一个算法，基准换成当月最早那一次：`当月最早一次记录到的余额 − 当前余额` |

官方**没有用量或账单接口**（API 文档里只有 Chat / Responses / FIM / 模型列表 / 余额 / 文件，控制台那个数字不对外开放），所以消费只能用余额快照做减法。每次打开首页或点「刷新」记一次，`deepseek.json` 里一天一条（留当天首次和末次），只保留最近 62 天。

几点说明：

- 这两个消费数字只覆盖**开始记录之后**的时段：今天第一次记录是 14:00，当天消费就从 14:00 起算；月中才开始记录，当月消费只能从那天算起。想从月初算起，得在月初打开过一次首页
- 期间充值（或退款）会让数字偏小，算出来低于 0 时按 0 显示
- 5 分钟内不重复请求，点「刷新」可以强制。断网时显示上次的数字
- 卡片上的「说明」写了这套口径，里面还有「打开平台用量页核对」按钮
- 没配密钥、接口返回 401 或连不上时，卡片只显示原因和「重新读取」，不影响首页其它部分

## 云同步（可选）

数据先在本地加密，再传到腾讯云 CloudBase 云存储。电脑端照旧用「数据文件夹」（明文 JSON，随时能自己打开改），手机端用浏览器打开 HTTPS 页面，数据落在 IndexedDB，**云端是权威副本**。

### 开一次要做的五件事

1. 腾讯云控制台开通 **CloudBase 云开发**，建一个环境，复制**环境 ID**（形如 `workbench-1a2b3c`）
2. 控制台 → 登录授权 → 打开**匿名登录**（同步用它换临时凭证，密钥不进前端）
3. 控制台 → **云存储** → 建一个桶，名字用 **`workbench`**（代码里默认就认这个桶名），并让匿名身份能读写它
4. 把这份页面放到任意 **HTTPS** 静态托管（CloudBase 静态网站托管自带 `https://xxx.tcloudbaseapp.com`，也可以用 Vercel / GitHub Pages），手机访问这个地址
5. 工作台「设置 → 云同步」里填环境 ID、设一个同步密码（至少 6 位，别和资料库主密码一样），点「开启同步」，再选第一次以哪边为准

第 5 步不是只试着登录一下：它会**真往云端写一个探针文件再读回来**，确认「登录、桶、读写权限」三样都通才继续。哪一样不通就当场报错，并告诉你该去控制台改什么（候选里有旧域名 / 桶不存在 / 权限策略 / 环境 ID 之分）；失败会自动回滚这次配置，不会留半套。

手机上不想手输环境 ID：电脑端把第 4 步的地址填进「手机访问地址」，面板会生成一个二维码，用手机相机扫一下就会打开工作台并带上环境 ID，再输一次同步密码即可。

### 同步哪些数据

| 同步 | 不同步 |
|---|---|
| 待办 `todos.json`、周报 `reports.json`、笔记索引 `notes.json` + 每篇正文 `notes/*.md`、记账 `ledger.json`、菜谱 `recipes.json`、软件号 `software.json`、加密资料库 `vault.json`、记谱 `charts.json`、记谱偏好 `chart-settings.json`（只取擅长和弦与推荐调权重） | 剪贴板历史、产品目录 `catalog.db`、OTDR 索引、局域网收到的文件、`workbench.config.json`、API Key |
| 项目清单：只取 `meta.json` 里的项目名，工具路径、git 根目录这些**本机路径不外传** | DeepSeek 余额快照 `deepseek.json`（每台设备各查各的，同步过去只会互相覆盖、反复产生冲突副本）、记谱的音量（擅长和弦与推荐调权重会同步，音量是设备属性，各台设备各留各的）、收藏 `files.json`（它指向 `files/` 里的二进制本体，那些不上云，同步过去只会得到一堆打不开的卡片）、资料库主密码、明文缓存 `wb-vault-records`、旧版明文资料库 `resources.json`（建议直接删掉） |

这张表不是死的：面板里「会同步哪些数据」区块会按这台设备**实际有什么**列出来，标上各自大小和待推送篇数，改动前后一眼能看出哪类还没上云。同一个区块也把「不上云」写在末尾，不用回来翻文档。

### 两台设备改了同一处怎么办

按文件或一篇笔记判定：谁后写谁说了算，被覆盖的那版自动存成**冲突副本**（笔记会多一条「（冲突副本 · 设备 · 时间）」，JSON 会多一个 `*.conflict-*.json`），在「设置 → 云同步」里可以查看、恢复、删除。**绝不静默丢数据**。

判定新旧用的是云端清单里的递增版本号，不是时间戳——设备时钟不准也不会判反。

### 什么时候同步

打开页面先拉一次（在渲染前完成，看到的就是最新数据）；改动后约 3 秒自动推；顶栏「同步」点开是面板，里面有「立即同步」。**不做后台轮询**，省请求也省钱（CloudBase 免费额度按月计，省下来的都是真额度）。

具体省在三处：

- **切页 / 刷新不白跑**：刚同步成功过、本机又没有待推的改动时，进页面这一轮**整轮跳过**（窗口 30 秒），连「读一次云端清单」都不做。在一堆页面之间来回切，不会每切一次就烧一次请求。
- **清单没变就不写**：一轮下来没有任何增删改，就不重写云端清单，顺带省掉「写清单前必读一次」那笔开销。
- **失败不算数**：跳过窗口以上一次**成功**同步为准。出过错之后切页会立刻重试，不会傻等窗口过期。

手动点「立即同步」、以及写完之后的自动推送**永远真跑**，不受上面两条影响——只要本机有改动，就一定推得上去。

### 面板里能看到什么

顶栏那个带圆点的「同步」就是入口，圆点颜色即状态（已同步 / 有改动待推送 / 同步中 / 出错 / 待解锁）。点开后面板分四块：

- **状态行**：当前状态 +「上次同步 X」（刚刚 / N 分钟前 / N 小时前）
- **健康度**：四格——「上次同步成功」「冲突副本」「版本差（云端领先几项 · 本地待推几项）」「最近一次失败」。失败会按**网络 / 凭证 / 权限 / 冲突**归类，并附一句该去查什么。算「版本差」需要读一次云端清单，所以只在**打开面板时**发生，不打开就不花这个请求
- **会同步哪些数据**：逐类列出会同步的东西、各自多大、有几篇笔记待推送，末尾写明哪些**不会**上云——不用翻文档也能自查
- **冲突副本**：查看 / 恢复 / 删除

### 手机上哪些功能没有

强依赖 Windows 本机服务的能力，在手机上**直接不显示入口**：代码（git）、更新软件版本、产品目录查询、剪贴板、局域网传文件。资料库页的「指定文件夹 / 在资源管理器打开」、快捷方式的「打开」、首页工具菜单也会收起。其余（待办、周报、笔记、记账、菜谱、项目、回收站、资料库增删查）在手机上都能用。

收藏页在手机上能打开，但**清单和本体都不上云**（`files.json` 指向 `files/` 里的二进制文件），所以手机上看到的是新的空列表。记谱的歌曲跟着同步走，手机上能接着看。

### 限制与风险

- **密钥不进前端**：CloudBase 用匿名登录换临时凭证，不像直连对象存储那样把 SecretKey 放在浏览器里。但环境 ID 是公开的，所以**所有数据都端到端加密**，别人就算匿名登录进来拿到的也只是一堆解不开的密文
- **匿名登录要你自己开**：没开的话面板会提示去控制台开启
- **必须 HTTPS**：非安全上下文下浏览器不提供 `crypto.subtle`，同步用不了，手机上也进不去数据页
- **不做离线**：手机上断网只有上次缓存，离线可用需要 Service Worker（现在没有）
- **跨设备不是实时**：同步靠「打开页面 / 改动」触发，没有长连接推送。手机改完，电脑要等下一次真同步才看得到；受上面那个 30 秒窗口影响，最坏情况是多等半分钟。想立刻对齐就点「立即同步」
- **云 SDK 要带对象存储接口**：上传下载走 `app.storage.from(桶名)` 这套对象接口（老接口在新一代环境下会一律回 `INVALID_PARAM`）。仓库里带的 `js/vendor/cloudbase.full.js` 已经是可用的那份，别换成旧版
- **桶名固定 `workbench`**：适配器默认只认这个桶名（配置里的 `bucket` 字段可覆盖，但面板上没有输入框，实际就是默认值），控制台建桶时名字要对得上
- **清浏览器数据会清掉 IndexedDB**：手机端的权威副本在云端，重新打开会自动拉回来
- **同步密码改不了**：只能「关闭同步」再重新配一次，重配时选「以本机为准」把数据重新推一遍
- 本机同步基准 `sync-state.json` 存在数据文件夹里，不参与同步；桶里 `workbench/` 前缀下全是密文

## 重新编译本地服务

改动 `scripts/workbench-host.cs` 后：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-host.ps1
```

脚本会：备份当前 exe → 用 `csc` 编译 → 停掉旧进程 → 替换 → 重启。**编译失败不会动正在用的 exe**；需要回滚时执行 `build-host.ps1 -Rollback`。

## 数据与隐私

- 待办、周报、笔记、记账、记谱、资料库全部写在你选择的数据文件夹里，是**可读的纯 JSON 文件**（收藏页存进来的文件本体也在同一个文件夹的 `files/`、`screenshot/` 里），随时可以自己备份、查看、手工修改
- 资料库用主密码加密（AES-GCM），密文落盘为 `vault.json`，每次保存前会留一份 `vault.backup.json`
- 「DeepSeek」的余额和按天快照存在数据文件夹的 `deepseek.json`（明文可读可改，一天一条，只留最近 62 天）
- **没开云同步时**，除 AI 润色（把周报文本发给你自己配置的模型接口）和首页余额查询（只带 API Key 问一次余额）外，**没有任何数据离开本机**
- **开了云同步后**，同步范围内的文件会**在本地加密后**传到你自己开通的腾讯云 CloudBase 环境，解密只在本机进行，云端只存密文；剪贴板历史、API Key、主密码、明文缓存、本机路径类配置都不在同步范围内（详见「云同步」一章）
- 本仓库已排除：`notes/`（数据）、`vault*.json`、`lan/`、`clipboard-history.json`、`catalog.db`、`otdr_index.db`、`js/openrouter.local.js`（密钥）、`workbench.config.json`（本机路径）
